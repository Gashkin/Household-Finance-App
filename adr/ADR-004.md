# ADR-004: Planner and consumer access model
- Status: Accepted
- Date: 2026-06-28
- Context: The audit highlighted the need to define the ownership and access boundaries between the planner and the consumer.
- Decision: Use separate roles with the planner able to edit financial data and the consumer restricted to read-only reporting views.
- Constraints: The consumer interface should remain simple and not support financial editing.
- Rules out: Shared editing permissions for the consumer role in v1.
- Supersedes: None
