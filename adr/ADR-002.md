# ADR-002: Transaction intake approach
- Status: Accepted
- Date: 2026-06-28
- Context: The Zachman audit identified transaction intake as a core decision because the spreadsheet currently relies on manual and implicit processes.
- Decision: Support transaction import from CSV or spreadsheet-style files with normalization, deduplication, and review before the data is accepted.
- Constraints: The first release does not require direct bank API connectivity or automated feeds.
- Rules out: Fully automatic bank synchronization in v1.
- Supersedes: None
