# ADR-003: Implementation shape and stack
- Status: Accepted
- Date: 2026-06-28
- Context: The audit identified the technology shape as a gating decision for the implementation path.
- Decision: Deliver a browser-based application hosted locally on a household machine or small home server, using React with TypeScript for the frontend and Spring Boot with Java for the backend.
- Constraints: The initial implementation should remain simple and local-first rather than introducing a large distributed architecture.
- Rules out: A desktop-only native app and a fully cloud-hosted service in v1.
- Supersedes: None
