## Existing Systems and Integrations
The system should seed its data from the existing spreadsheet. It should not include the random other spreadsheets that are not part of monthly budgeting.

## Future Possibilities (not v1)
Specific event financial planning such as Christmas and holidays, and tax calculations.

## Irreducible Core
The irreducible core is the ability to see current balances, upcoming commitments, and allowable spend in a simple and trustworthy way.

## Known Uncertainties
The biggest uncertainty is how transaction automation should work. If scope had to be cut, automating transactions would be the first thing to cut. The exact design of that automation is still uncertain.
